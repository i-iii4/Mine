Полная карта клавиатурных команд Mine. Принята 23.08.2026 по итогам аудита
сочетаний; решения пользователя зафиксированы в PLAN.md (раздел K1–K9).

## Статус сочетаний

Таблицы ниже — **умолчания**. С 24.08.2026 сочетания переназначаются в разделе
Shortcuts окна настроек; переопределения хранятся в `config.json` приложения и
применяются поверх умолчаний.

## Источник истины

`src/lib/commandRegistry.ts` — единственное место, где команда получает
сочетание, имя и контекст. Привязка — данные (`CommandBinding`: клавиша плюс
модификаторы), а не рукописный матчер: подпись и сопоставление выводятся из
одной записи, поэтому переназначение вообще возможно. Нижняя панель, оверлей ⌘/ и обработчики читают
оттуда: сочетание не может разойтись между местом, где оно показано, и местом,
где оно реализовано. Матчеры проверяют модификаторы точно: команда на ⌘ не
срабатывает на ⌘⇧.

Нативное меню (Rust, `src-tauri/src/lib.rs`) дублирует четыре команды со
своими акселераторами: Settings ⌘,, Find Elements ⌘F, Find Collections ⌘⇧F,
Hide Sidebar ⌃⌘S. В упакованном приложении акселератор меню владеет ⌃⌘S —
webview-обработчик уступает, чтобы не переключать панель дважды. С 03.10.2026
пункт Hide Sidebar исполняет бэкенд: он сворачивает боковое меню окна вкладок в
фокусе, а без него последнего окна вкладок (SPEC_TABS.md, В56). Там же пункты
вкладок и окон (раздел «Вкладки и окна»).

| ⌃⌘S | Hide/Show Sidebar | В Tauri владеет нативное меню |
| ⌘⇧N | New Collection | Панель открыта — строка в списке; закрыта — диалог |
| ⌘, | Settings | Нативный пункт меню |
| ⌘F | Find elements | Оверлей поиска |
| ⌘⇧F | Find collections | Поиск по боковой панели |
| ⌘⇧O | Switch space | Смена хранилища |
| ⌘[ / ⌘] | Back / Forward | История маршрутов |
| ⌘/ | Commands | Открывает настройки на разделе Shortcuts |
| ⌘⌥↑↓ | Switch collection | Только при открытой боковой панели: перебор списка, которого нет на экране, запрещён. Работает при открытом элементе — элемент закрывается вместе с покидаемой коллекцией |

## Вкладки и окна

С 03.10.2026 ([SPEC_TABS.md](SPEC_TABS.md), В55, от В57 до В59). Эти сочетания
macOS закрепляет за вкладками и окнами во всех приложениях, поэтому команды не
переназначаются (`fixed: "system"`).

| Сочетание | Команда | Пункт нативного меню |
|---|---|---|
| ⌘T | New Tab | File → New Tab |
| ⌘N | New Window | File → New Window |
| ⌘W | Close Tab | File → Close Tab |
| ⇧⌘W | Close Window | File → Close Window |
| ⇧⌘], ⌃⇥ | Show Next Tab | Window → Show Next Tab |
| ⇧⌘[, ⌃⇧⇥ | Show Previous Tab | Window → Show Previous Tab |
| ⌘1 по ⌘8 | Select Tab 1 to 8 | Window → Select Tab с номером |
| ⌘9 | Select Last Tab | Window → Select Last Tab |
| без сочетания | Move Tab to New Window | Window → Move Tab to New Window |

Сочетания с ⌘ это пункты нативного меню (`build_app_menu` и `on_menu_event` в
`lib.rs`). Меню получает сочетание раньше страницы, поэтому команда работает в
любой странице окна, в полосе вкладок тоже. Пункт действует на окно вкладок в
фокусе, а без него на последнее окно вкладок. Пункты File свои, а не готовый
`close_window` из muda: тот намертво занимал бы ⌘W. Close Tab и Close Window
закрывают окно настроек, когда оно в фокусе.

⌃⇥ и ⌃⇧⇥ (⌃Tab и ⌃⇧Tab) меню не принимает: их ловят сами страницы вкладки и полосы
(`adjacentTabDirection` в `src/tabbar/tabKeyboard.ts`) и передают бэкенду
командой `activate_adjacent_tab`. Страница вкладки слушает их в фазе перехвата,
поэтому они работают из любого экрана, из полей и диалогов тоже. Простой ⇥
(Switch view) требует точного набора модификаторов и с ⌃⇥ не пересекается.

New Tab открывает пространство видимой вкладки окна на Everything, New Window
пространство видимой вкладки последнего окна (В51, В54). Следующая и
предыдущая вкладка идут по кругу. ⌘1 по ⌘8 выбирают вкладку по номеру и ничего
не делают, если вкладки с таким номером нет; ⌘9 всегда выбирает последнюю.

В реестре эти команды записаны как остальные, подписи берутся из общего
словаря клавиш (`commandBinding.ts`). Второе и следующие сочетания команды
лежат в поле `alternates` и сопоставляются так же, как основное; ⌘1 по ⌘8 это
одна команда `select-tab` с признаком `run` и одной подписью `⌘1…⌘8`. Больше
одного сочетания бывает только у команды, которую нельзя переназначить. В
разделе Shortcuts команды вкладок и окон показаны только для чтения
([SPEC_SETTINGS_WINDOW.md](SPEC_SETTINGS_WINDOW.md), «Shortcuts»).

## Graph

Граф — курсорная поверхность (решение 23.08.2026): выбор, открытие,
перетаскивание и панорамирование — жесты мыши; клавиатурных обработчиков в
графе нет, холст не фокусируем. Глобальные команды работают над графом,
поскольку слушают окно.

## Нижняя панель при сужении окна

Записи скрываются целиком; усечение запрещено. Факт переполнения берётся из
раскладки (`scrollWidth > clientWidth` на панели), а не вычисляется из ширин.

Порядок: справочные (`Navigate`, `Switch collection`) → esc-записи (`Close`,
`Clear selection`) → заученные (`Settings`, `Hide Sidebar`, `New Collection`,
`Find elements`, `Commands`) → ситуативные (`Command`, `Focus`).

Тесты: `src/lib/bottomBarOverflow.test.ts` закрепляет порядок,
`src/App.test.tsx` («hides bar entries by worth when the window is too narrow»)
прогоняет настоящий путь измерения и проверяет, что остаток действительно
помещается.

## Переназначение

**Что переназначается.** Любая команда, кроме помеченных `fixed`:

- `structural` — стрелки, `Enter`, `Escape`, `Tab`, `⇧↵`, `⌘⌥↕`. Это язык
  интерфейса, а не сочетания; подмена ломает саму модель работы. В настройках
  не показываются.
- `system`: `⌘,` на Settings и с 03.10.2026 сочетания вкладок и окон
  (раздел «Вкладки и окна»). macOS ожидает их на этих командах. В настройках
  показываются строкой только для чтения: подписи сочетаний без записи.

Переопределение для `fixed`-команды игнорируется реестром: молча не
работающая настройка хуже её отсутствия.

**Ввод.** Поиск фильтрует список при каждом вводе по названию команды,
отображаемым символам сочетания и текстовой записи клавиш, например `cmd+f`.
Несколько слов запроса могут совпасть с разными частями одной записи. Пустая
выдача прямо сообщает, что совпадений нет. Список ограничен по ширине до 720
пикселей. Каждая обычная строка имеет высоту не менее 40 пикселей. Короткое
сочетание занимает компактную кнопку высотой 24 пикселя, кнопки выровнены по
правому краю. Нажатие на действующее сочетание переводит эту же строку в режим
записи. Допустимое сочетание сразу сохраняется, отдельные кнопки подтверждения
и отмены не нужны. `Escape` или уход фокуса отменяют запись, `Tab` сохраняет
обычную навигацию. Запись другой строки закрывает предыдущую. При возврате к
исходному сочетанию переопределение удаляется. Кнопка сброса видна только для
изменённой команды рядом с её названием. Она не занимает общую колонку и не
сдвигает сочетание. Сбросы используют компактные вторичные кнопки.

Пока запись активна, нативное меню macOS временно снимается, поскольку его
акселераторы перехватывают нажатия до окна настроек. При сохранении, отмене,
потере фокуса окна или его закрытии меню пересоздаётся из действующих
сочетаний. Если сохранение в конфигурацию не удалось, прежняя привязка
остаётся действующей и ошибка показана в строке. Голая клавиша отклоняется.
Структурные команды отсутствуют в списке настроек, системные показаны в нём
только для чтения. Скобки записываются по физической клавише (`event.code`
`BracketLeft` и `BracketRight`): ⇧⌘[ на раскладке США приходит как `{`.

**Проверки.** Отклоняются системные сочетания macOS (`⌘Q`, `⌘W`, `⌘M`, `⌘H`,
`⌘Tab`, `⌘Space`, `⌘⇧3/4/5` и прочие) и конфликты внутри одновременно активных
контекстов: `feed`, `element` и `selection` взаимоисключающи, поэтому одно
сочетание может значить в них разное, но глобальная команда не может занять
сочетание, используемое любой поверхностью. Конфликт блокирует назначение и
называет команду-соперника. Конфликт считается со всеми сочетаниями команды,
включая `alternates`.

С 03.10.2026 список запрещённых сочетаний (`RESERVED` в
`src/lib/shortcutValidation.ts`, записан привязками и сравнивается через
`bindingId`) дополнен сочетаниями вкладок и окон: ⇧⌘W, ⌘1 по ⌘9, ⇧⌘[ и ⇧⌘]
(а также `{` и `}`, которые раскладка США отдаёт при Shift), ⌃⇥ и ⌃⇧⇥; ⌘T,
⌘N и ⌘W в нём уже были. Переназначение, сохранённое прежней сборкой на одно
из этих сочетаний, отбрасывается при чтении (`reserved_for_tabs` и
`load_overrides` в `src-tauri/src/commands/shortcuts.rs`): команда
возвращается к своему сочетанию по умолчанию, в журнал пишется событие.
⌘[ и ⌘] без Shift остаются за историей страниц.

**Хранение.** `config.json` на стороне Rust, не `localStorage`: переопределения
читает нативное меню, и очистка данных сайта не должна их терять. Сохранение
рассылает `shortcuts-changed` всем страницам: вкладки, полосы вкладок и окно
настроек перечитывают реестр без перезапуска.

**Нативное меню.** `Settings`, `Find Elements`, `Find Collections`,
`Hide Sidebar` продублированы акселераторами. Пункты вкладок и окон
переопределений не читают: их сочетания закреплены. Меню собирается из тех же
переопределений (`build_app_menu`) и перестраивается при сохранении: в macOS
акселератор меню перехватывает событие раньше webview, поэтому устаревшее меню
вызывало бы старую команду или глотало новую.

**Сброс.** По одной команде и всё сразу. У изменённой команды появляется
кнопка `Reset`. Ошибка сохранения оставляет прежнее сочетание действующим.

## Решения, принятые сознательно

- Удаление и переименование элементов не имеют прямых сочетаний: покрытие —
  меню ⌘K. Разрушающее действие за меню — защита от случайного нажатия.
- `Navigate` и `Switch collection` — справочные записи панели, не кнопки: у
  перебора есть направление, одного действия для клика нет.
- Пары esc/↵/⌘K значат разное в лентe, элементе и выделении — контексты
  взаимоисключающие, внутри одного контекста плюс Global сочетание значит одно
  (юнит-тест уникальности в `commandRegistry.test.ts`). ⇥ элемента сознательно
  затеняет глобальный ⇥.
