# SPEC: Scroll edge fade

Related documents: [ARCHITECTURE.md](ARCHITECTURE.md) | [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) | [PRINCIPLES.md](PRINCIPLES.md) | [SPEC_SETTINGS_WINDOW.md](SPEC_SETTINGS_WINDOW.md) | [SPEC_FRONTEND.md](SPEC_FRONTEND.md)

## Задача

Прокрученный контент упирается в верхний chrome жёстким срезом: строка обрывается
ровно по кромке. Опциональное растворение верхней кромки убирает этот срез —
контент истаивает в прозрачность, уходя под chrome.

Эффект применяется к четырём прокручиваемым поверхностям: боковая панель, лента,
развёрнутая карточка и результаты поиска.

## Растворение, не тень

Это **маска**, а не `box-shadow` и не тёмная накладка.

| Подход | Почему отвергнут |
|---|---|
| Тёмный градиент поверх контента | В светлой теме читается как грязное пятно, в тёмной почти не виден. Требует отдельных значений на тему |
| `box-shadow` у кромки | `box-shadow` в Mine зарезервирован за всплывающими элементами; разделение планов делается уровнями фона, границами и масками (см. `DESIGN_SYSTEM.md`) |
| Накладка градиентом цвета фона | Дёшево, но требует знать точный цвет под каждой поверхностью и разваливается на неоднородном фоне |
| **Маска прозрачности** (выбрано) | Контент действительно становится прозрачным, поэтому эффект не зависит ни от темы, ни от того, что лежит под поверхностью |

Кривая — та же, что уже используется в боковой панели для правой кромки строк и
превью. Одна кривая на все кромки: `src/lib/edgeFade.ts`.

## Контракт кривой

Ширина рампы различается по кромкам:

- `EDGE_FADE_WIDTH = 24` — правая кромка боковой панели;
- `TOP_FADE_WIDTH = 12` — верхняя кромка прокручиваемых поверхностей.

Верхняя рампа вдвое уже намеренно. Правая кромка гасит целую строку текста вбок и
нуждается в запасе, чтобы текст оставался читаемым в середине затухания. Верхней
достаточно смягчить момент ухода контента под chrome: более тугая рампа читается
как аккуратная обработка кромки, а не как широкая дымка поверх первой строки.

Рампа задана девятью парами `alpha / progress`, где `progress` — нормализованная
доля пути по рампе (`0` — непрозрачное начало, `1` — полностью прозрачная кромка):

| alpha | progress |
|---|---|
| 0.82 | 0.14 |
| 0.64 | 0.24 |
| 0.49 | 0.33 |
| 0.36 | 0.45 |
| 0.25 | 0.57 |
| 0.16 | 0.69 |
| 0.09 | 0.81 |
| 0.04 | 0.9 |
| 0.01 | 0.97 |

Рампа намеренно нелинейна: линейное изменение альфы воспринимается как жёсткая
полоса, потому что воспринимаемая непрозрачность падает быстрее самого значения
альфы.

Обе кромки строятся из одного набора:

- `createRightFadeMaskStyle(fadeWidth, clearTailWidth)` — непрозрачно слева,
  прозрачно справа. `clearTailWidth` резервирует полностью прозрачный хвост под
  колонку действий строки боковой панели.
- `createTopFadeMaskStyle(fadeWidth)` — зеркально и с порогом: у самой кромки
  остаётся `TOP_FADE_MIN_ALPHA = 0.12`, полная непрозрачность наступает через
  `fadeWidth` пикселей ниже. Резервного хвоста нет — у верхней кромки нечего
  освобождать.

**Верхняя рампа не доходит до нуля.** Контент, растворяющийся полностью,
читается как обрезанный: строка просто заканчивается. Слабый остаток читается
как контент, продолжающийся за chrome. Правая кромка по-прежнему уходит в полную
прозрачность — там она скрывает переполнение текста, а не границу.

Форма кривой сохраняется: значения рампы линейно перенесены из диапазона
`[0, 1]` в `[TOP_FADE_MIN_ALPHA, 1]`, поэтому перцептивный профиль совпадает с
правой кромкой.

Функции выставляют одно и то же значение в `maskImage` и `WebkitMaskImage`.

## Условие появления

Маска включается только когда поверхность действительно прокручена:
`scrollTop >= TOP_FADE_SCROLLED_THRESHOLD_PX` (`1`). В покое первая строка обязана
оставаться полностью непрозрачной.

Порог в один пиксель отсекает субпиксельные смещения, которые приходят при
инерционной прокрутке и ресайзе; меньше пикселя контент скрыть не может.

Выключенная настройка и покой дают `undefined` — элемент остаётся вовсе без
mask-свойств, а не с `mask-image: none`.

## Два пути активации

| Путь | Кто использует | Почему |
|---|---|---|
| `topFadeMaskStyleFor(enabled, scrollTop)` | Лента | Grid уже держит собственный `scrollTop` для виртуализации. Второй слушатель `scroll` в горячем пути ленты не нужен |
| `useTopFadeMask(ref, enabled)` | Боковая панель, развёрнутая карточка, поиск | Эти поверхности своё смещение не отслеживают |

Хук хранит одно булево состояние — «прокручена ли поверхность», — а не смещение,
поэтому обычная прокрутка не вызывает повторный рендер после включения маски.

**Подключение идёт через callback ref, а не через ref-объект.** Поиск живёт внутри
Radix `Dialog`, который не монтирует содержимое, пока окно закрыто: список
результатов появляется в более позднем рендере, чем сам компонент. Ref-объект на
момент выполнения эффекта был бы пуст, а эффект больше не перезапустился бы —
такая поверхность молча никогда не растворялась бы.

`useTopFadeMask(forwardRef, enabled)` возвращает `{ ref, style }`. Переданный
`forwardRef` продолжает заполняться тем же узлом, поэтому хук добавляется к
поверхности, не ломая то, что уже использует этот ref для фокуса или прокрутки.

## Поверхности

| Поверхность | Скроллпорт | Атрибут состояния |
|---|---|---|
| Боковая панель | `[data-sidebar-scroll]` | `data-sidebar-top-fade` |
| Лента | `[data-grid-scroll]` | `data-grid-top-fade` |
| Развёрнутая карточка | `[data-detail-scroll]` | `data-detail-top-fade` |
| Поиск | `#search-overlay-listbox` | `data-search-results-top-fade` |

Атрибут присутствует только когда маска активна, и предназначен для проверок.

В ленте маска добавляется к существующему `style` через spread, а не вместо него:
скроллпорт держит собственные `padding`, `scrollbarGutter` и `transition`.

## Настройка

Ключ: `mine.scrollEdgeFade`. Выключено по умолчанию — эффект необязательный, и
чистая установка сохраняет прежнюю жёсткую кромку.

Хранение и синхронизация — по общему контракту настроек: окно настроек пишет
`localStorage` и вызывает `broadcastSettingsChange(SCROLL_EDGE_FADE_STORAGE_KEY)`,
главное окно перечитывает ключ в обработчике `settings-changed` и передаёт
значение в четыре поверхности пропом `scrollEdgeFade`.

Строка в разделе Appearance: `Fade content under the chrome`.
